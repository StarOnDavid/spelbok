🎵 Refactor: Rebrand "Musik Repertoire" to "SpelBok" and modernize architecture

## Major Changes

### 🎨 Rebranding: Musik Repertoire → SpelBok
- Renamed application from "Musik Repertoire" to "SpelBok" (Swedish for "songbook/playbook")
- Updated all UI text and translations across 3 languages (SV/DE/EN)
- New taglines:
  - Swedish: "Din digitala spelbok" (Your digital songbook)
  - German: "Dein digitales Liederbuch" (Your digital songbook)
  - English: "Your digital songbook"

### 🏗️ Architecture Refactoring
- Split monolithic 56KB HTML file into modular structure
- Separated concerns: HTML, CSS, and JavaScript in dedicated files
- Organized assets into logical folder hierarchy
- Improved maintainability and scalability

### 📁 New Structure
```
spel_bok/
├── index.html              # Main entry point (modular)
├── manifest.json           # PWA manifest (updated)
├── sw.js                   # Service worker (enhanced)
├── assets/
│   ├── css/styles.css     # Standalone stylesheet (7.4KB)
│   ├── js/app.js          # Application logic (14KB)
│   └── icons/             # PWA icons directory
├── docs/                   # Documentation moved here
│   ├── README.md
│   ├── PWA-INSTALLATION.md
│   ├── PWA-QUICKSTART.md
│   └── PWA-STRUKTUR.md
├── CHANGELOG.md            # Version history
├── GETTING_STARTED.md      # Setup guide
└── PROJECT_STRUCTURE.md    # Architecture docs
```
